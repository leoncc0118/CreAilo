# CreAilo

**用畫布整理想法，和 AI 創作夥伴一起完成作品。**

CreAilo 是正在開發中的桌面創作工具。你可以在無限畫布上安排圖片、文字與版面，把參考素材連到 Prompt，再讓創作夥伴協助規劃、生成與調整內容。

適合漫畫分鏡、角色設計、故事構思與視覺草稿，也能作為自由排列素材的創作空間。

## 可以做什麼

- **無限畫布**：透過 Section、Frame 與 Panel 安排版面，匯入、移動及調整圖片。
- **Prompt 工作流**：以曲線連接參考素材、Prompt 與目標，生成結果加入指定版面。
- **創作夥伴**：用聊天提供劇本或指令，協助建立版面、角色、Prompt 與生成排程。
- **可編輯對白**：自動建立對白框與文字後，仍可手動調整內容、位置與尾巴。
- **本機專案**：圖片与版面資料儲存在本機專案資料夾，可輸出 PNG。
- **分開選擇協作模型與生圖引擎**：協作模型可連接 Codex 或 Claude Code；目前生圖引擎使用 Codex 的圖片生成能力。

## 第一次使用

1. 下載並解壓縮測試包，將 `CreAilo.app` 拖入「應用程式」。
2. 開啟 CreAilo，建立專案並選擇本機儲存位置。
3. 不使用 AI 時，可以先匯入圖片、排列版面及加入文字。
4. 要使用 AI，請先依照 [使用指南](docs/GETTING_STARTED.md) 安裝相關 CLI，再透過右上角的 **AI 帳號** 連接自己的帳號。
5. 在編輯頁打開 **創作夥伴**，或建立 Prompt 並連到 Frame／Panel。

測試版尚未使用 Apple Developer 簽章與公證。macOS 可能阻止開啟；確認下載來源與 SHA-256 後，可前往「系統設定 → 隱私權與安全性」查看是否有「仍要打開」。受管理的電腦可能無法允許執行。

## AI 帳號與資料

CreAilo 不附贈 AI 額度，也不提供共用 AI 帳號。AI 功能需要使用者自己的帳號與本機 CLI；實際可用功能及額度依提供者與帳號而定。

專案保存在本機。使用 AI 時，指令、相關參考圖片及版面資訊會提交給選定的 AI 服務；**本機儲存不代表 AI 功能完全離線**。帳號憑證由相關 CLI 管理，不寫入專案。
